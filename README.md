# Hotel-Reservation-System
A hotel reservation system where users can search for available rooms, make reservations, and view booking details.

>Features:
-Search for available rooms by category
-Make reservations and view booking details
-Room categorization (AC/Non-AC, etc.)

It demonstrates CRUD operations, routing, and basic frontend integration with templates.
